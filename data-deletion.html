データ削除ガイド Data Deletion Guide

SUPLEX に保存されたすべてのデータを完全に削除する手順 How to completely delete all data stored by SUPLEX

サマリー

SUPLEX はローカルファースト型アプリです。データは すべてユーザーの PC 上のみ に存在し、外部サーバーには保存されません。以下の手順で完全削除できます。

STEP 01

各 SNS の認可を取り消す

SUPLEX アプリ内の「チャンネル」タブで対象アカウントの「削除」ボタンを押すか、各プラットフォームの設定画面から SUPLEX を取り消します：

  • Instagram / Facebook: 設定 → アプリとウェブサイト → SUPLEX を削除
  • TikTok: 設定 → セキュリティとプライバシー → 接続アプリ → SUPLEX を削除
  • YouTube (Google): myaccount.google.com → セキュリティ → サードパーティアクセス → SUPLEX を削除
  • X: 設定 → セキュリティとアカウントアクセス → アプリとセッション → SUPLEX を取り消し
  • Bluesky: 設定 → 接続アプリ → SUPLEX を削除
STEP 02

ローカルデータベースを削除

Windows: %APPDATA%\SUPLEX\ フォルダー全体を削除

macOS: ~/Library/Application Support/SUPLEX/ を削除

Linux: ~/.config/SUPLEX/ を削除

STEP 03

アプリ本体をアンインストール

Windows: 設定 → アプリ → SUPLEX → アンインストール

macOS: Application フォルダーから SUPLEX.app をゴミ箱へ

完了の確認

3 ステップ完了後、ローカル PC およびすべての SNS プラットフォーム上から SUPLEX のアクセス権限は完全に消去されます。各プラットフォームのアプリ管理画面で SUPLEX が表示されないことを確認してください。

Summary

SUPLEX is a local-first app. All data exists only on your PC — nothing is stored on external servers. Follow these steps for complete deletion.

STEP 01

Revoke SNS authorizations

In the SUPLEX "Channels" tab, click "Delete" on the target account, or revoke SUPLEX from each platform's settings:

  • Instagram / Facebook: Settings → Apps and Websites → remove SUPLEX
  • TikTok: Settings → Security and Privacy → Connected Apps → remove SUPLEX
  • YouTube (Google): myaccount.google.com → Security → Third-party access → remove SUPLEX
  • X: Settings → Security and account access → Apps and sessions → revoke SUPLEX
  • Bluesky: Settings → Connected Apps → remove SUPLEX
STEP 02

Delete local database

Windows: delete the entire %APPDATA%\SUPLEX\ folder

macOS: delete ~/Library/Application Support/SUPLEX/

Linux: delete ~/.config/SUPLEX/

STEP 03

Uninstall the app

Windows: Settings → Apps → SUPLEX → Uninstall

macOS: Drag SUPLEX.app from Applications to Trash

Confirmation

After completing all 3 steps, SUPLEX's access permissions are fully removed from your local PC and all SNS platforms. Verify by checking that SUPLEX no longer appears in each platform's app management screen.
