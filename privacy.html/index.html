プライバシーポリシー Privacy Policy

最終更新: 2026年5月27日 Last updated: May 27, 2026

1. 基本方針

SUPLEX は、ユーザーのプライバシーを最優先に設計されたローカルファースト型のデスクトップアプリケーションです。本アプリは原則として個人データをクラウドサーバーに送信せず、ユーザー自身のコンピューター上でのみ動作します。

2. 収集する情報

データ種別保存場所目的
SNS アクセストークンユーザー PC (OS 暗号化)各 SNS API への接続
アカウント識別子（ユーザー名等）ユーザー PC (SQLite)UI 表示
投稿コンテンツ（テキスト・画像・動画）ユーザー PC各 SNS への投稿
投稿履歴・結果ユーザー PC結果表示・再試行

本サービスはユーザーの個人データを SUPLEX 運営側のサーバーに送信しません。投稿時に各 SNS の API へ直接通信します。

3. 第三者への提供

ユーザーが投稿する際、コンテンツは選択された SNS プラットフォーム（Instagram, TikTok 等）へ送信されます。これらは各プラットフォームのプライバシーポリシーに従って取り扱われます。

  • Instagram プライバシーポリシー
  • Facebook プライバシーポリシー
  • TikTok プライバシーポリシー
  • Google (YouTube) プライバシーポリシー
  • X プライバシーポリシー
  • Bluesky プライバシーポリシー

4. データ保管期間

すべてのデータはユーザー PC 上に保存され、ユーザーがアンインストールするか手動で削除するまで保持されます。SUPLEX 運営側は保管期限を制御しません。

5. ユーザーの権利

ユーザーはいつでも以下を実行できます：

  • 各 SNS の認可を取り消す（アプリ内ボタン または 各プラットフォームの設定）
  • SUPLEX の全ローカルデータを削除する
  • 本アプリをアンインストールする

詳細手順は データ削除ガイド を参照。

6. セキュリティ対策

  • アクセストークンは Windows DPAPI 等の OS 暗号化機能で保護されます
  • HTTPS 経由でのみ各 SNS API と通信します
  • OAuth コールバックはローカル（127.0.0.1）のみで受信します

7. 子どもの利用

本サービスは 13 歳未満（日本以外では現地法で定める年齢未満）のユーザーを対象としていません。

8. 国際的な利用

本アプリは日本を拠点として運営されていますが、世界中からアクセス可能です。ローカルファースト設計のため、各国のデータ移転規制（GDPR、CCPA 等）に対しては SUPLEX 側で個人データを保持しない仕組みで対応しています。

9. ポリシー変更

本ポリシーは予告なく変更される場合があります。変更時は本ページに反映され、重要な変更はアプリ内通知も行います。

1. Core Principle

SUPLEX is a local-first desktop application designed with user privacy as the top priority. By default, the app does not transmit personal data to cloud servers — it operates only on the user's own computer.

2. Information We Collect

Data typeStored atPurpose
SNS access tokensUser's PC (OS-encrypted)Connecting to each SNS API
Account identifiers (usernames, etc.)User's PC (SQLite)UI display
Content (text, images, videos)User's PCPublishing to selected SNS
Publishing history & resultsUser's PCDisplay results, retries

This Service does not send personal data to SUPLEX-operated servers. At publish time, content is sent directly to each SNS API.

3. Third Parties

When you publish, your content is sent to the selected SNS platform (Instagram, TikTok, etc.). These platforms handle your data per their own privacy policies.

4. Data Retention

All data is stored on your PC and retained until you uninstall the app or manually delete it. SUPLEX does not control retention periods.

5. Your Rights

  • Revoke authorization on each SNS at any time (in-app button or platform settings)
  • Delete all SUPLEX local data
  • Uninstall the app

See the Data Deletion Guide for details.

6. Security

  • Access tokens are protected by OS-level encryption (Windows DPAPI, etc.)
  • Communication with SNS APIs is HTTPS-only
  • OAuth callbacks are received only on localhost (127.0.0.1)

7. Children's Use

This Service is not intended for users under 13 (or the age specified by local law).

8. International Use

This app is operated from Japan but accessible worldwide. Due to the local-first design, we comply with international data transfer regulations (GDPR, CCPA, etc.) by simply not holding personal data on SUPLEX-side servers.

9. Policy Changes

This policy may be revised without prior notice. Updates are reflected on this page, and significant changes are also notified in-app.
