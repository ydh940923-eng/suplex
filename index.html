FEATURES

作って、束ねて、一括で配信する。 Create, group, and broadcast — at once.

01

フォーマット自動変換 Auto-format

1:1, 9:16, 16:9 — 各チャンネルの最適比率に自動で変換・書き出し。 Automatically converts to 1:1, 9:16, 16:9 — each channel's optimal aspect ratio.

02

チャンネルグループ Channel groups

本アカウントと複数のサブアカウントを束ねて、一括投稿・分析。 Bundle main and sub-accounts into groups for batch publishing and analytics.

03

予約キュー Scheduled queue

下書き・予約・即時投稿の 3 段階キュー。最適な時間に自動配信。 Three-stage queue: draft, schedule, immediate. Auto-publish at optimal times.

04

公式 API のみ Official APIs only

各プラットフォームの公式 OAuth + Publishing API のみ使用。アカウント停止リスクなし。 Uses only official OAuth and Publishing APIs. No account-ban risk.

05

ローカルファースト Local-first

アクセストークンは OS の暗号化ストレージに保存。クラウドに送られません。 Access tokens are encrypted in OS storage — never sent to the cloud.

06

無制限チャンネル Unlimited channels

10 でも 100 でも、1 ライセンスで管理。サブブランド運用にも対応。 Manage 10, 100, or more channels with a single license — perfect for sub-brand operations.
